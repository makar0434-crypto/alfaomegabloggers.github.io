# AlfaOmega — статический сайт

Адаптивный сайт для GitHub Pages без сборки и внешних зависимостей.

## Локальный просмотр
Откройте `index.html` в браузере или используйте любой статический локальный сервер.

## Публикация на GitHub Pages
1. Загрузите содержимое папки в корень репозитория.
2. В GitHub откройте **Settings → Pages**.
3. Выберите публикацию из ветки `main`, папка `/ (root)`.
4. Сохраните и дождитесь URL публикации.

## Персонализация
- Контакт Telegram: `https://t.me/kenelmoder`.
- Кейсы намеренно оставлены как placeholders — замените текст и добавьте подтверждённые материалы.
- Примеры чисел (203 524 ₽, 695 613 ₽, 300 000 ₽, 10+) взяты из предоставленного ранее референсного контекста; это не обещание результата.
- Калькулятор — математическая модель сложного процента с настраиваемыми параметрами, не инвестиционный прогноз.
- Для музыки добавьте разрешённый к использованию оригинальный файл как `assets/music.mp3`. Автовоспроизведение не запускается до нажатия пользователя.

## Структура
- При открытии показывается заставка с рисующимся знаком `$`; кнопка «ВСЕ КЕЙСЫ» открывает сайт.
- Текстовые блоки проявляются при прокрутке; добавлены hover-эффекты и декоративные анимации.
- `index.html` — секции и контент
- `style.css` — адаптивная стилизация и анимации
- `script.js` — счётчики, калькулятор, меню и музыкальный переключатель
- `assets/music.mp3` — добавить самостоятельно
